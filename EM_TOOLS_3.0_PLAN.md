## 1. Миссия и цели проекта

Проект **«Electromagnetic Tools 3.0»** создаётся как флагманская наземная станция оператора и стендового инженера для линейки приборов электромагнитного каротажа во время бурения (LWD/Cartograph, зонды 4TX, 5TX, АМК-120 «Картограф»).

### Ключевые проблемы старого решения (`AIR_TEMP_1.0`):
1. **Эргономическая перегруженность:** сплошная строка из десятков разнородных кнопок в шапке окна без логической группировки.
2. **Тормоза MSChart при интерактивности:** задержки и рывки курсора при попытке перетаскивания и масштабирования из-за процессорной перерисовки GDI+.
3. **Разделенность инструментов:** калибровка инклинометра жила в отдельной программе (`MAGNETOMETR_CAL`), что требовало запуска двух независимых приложений.
4. **Легаси-наслоения:** за годы развития накопилось множество неиспользуемых веток, затрудняющих расширение.

### Главные задачи Electromagnetic Tools 3.0:
1. **Чистая архитектура с нуля:** сохранение 100% проверенной физико-математической базы при полностью переработанном, современном каркасе.
2. **Эргономичный UI в стиле карточек:** понятная пошаговая структура (в стиле `MAGNETOMETR_CAL`), крупные информативные индикаторы, наглядные статусы каналов.
3. **Отзывчивый графический движок (60 FPS):** быстрое панорамирование, аппаратная буферизация, мгновенное позиционирование визира времени без задержек.
4. **Бесшовная интеграция инклинометра:** вкладка калибровки магнитометра и акселерометра встроена прямо в главное окно станции.
5. **Сквозная совместимость с прошивкой:** прямое использование заголовочных файлов структур бортового микроконтроллера TMS320F28377S.

## 3. Архитектура графического интерфейса пользователя (UI)

### А. Базовая компоновка экрана:
* **Верхняя строка статуса:** имя подключенного прибора, IP/порт, частота кадров (FPS), пакетный счетчик потерь CAN/CRC.
* **Слева:** карточная панель управления (Cards / GroupBoxes в стиле `MAGNETOMETR_CAL`):
  * **Карточка 1: Связь** (Выбор источника: UDP / COM / Файл; кнопки Старт/Стоп с цветным индикатором).
  * **Карточка 2: Режим прибора** (Стенд / Каротаж / Диагностика).
  * **Карточка 3: Метрология** (Калибровка, ТЕСТ, экспорт RAW CSV).
* **Центральная рабочая область (Вкладки - TabControl):**
  * **Вкладка 1: «Каротаж и Секторы» (Основной экран 2+2)**:
    * Слева: 2 больших окна временных/глубинных кривых (верхнее: 2000 кГц / нижнее: 400 кГц).
    * Справа: 2 окна 16 азимутальных секторов (верхнее: Rx_L / нижнее: Rx_R).
    * Под каждым окном секторов — строка качества: $H_1/H_2$ (раз), Мусор $dv$ (мВ), SNR (дБ).
  * **Вкладка 2: «Инклинометрия / Годографы»**:
    * Встроенный интерфейс `MAGNETOMETR_CAL` (годограф сферы/окружности, калибровка нулей, ToolFace).
  * **Вкладка 3: «Здоровье прибора (Health Matrix)»**:
    * Светофор состояния модулей Tx1..Tx5, Rx_L, Rx_R, температура, питание, коды отказов `condition`.
* **Нижняя полоса (Status Bar & Схема зонда)**:
  * Интерактивная схема зондов картографа с подсветкой активной базы.
  * Паспорт загруженного файла при оффлайн-просмотре.

## 4. Пошаговая дорожная карта реализации (Roadmap)

### Этап 1. Базовый каркас решения в Visual Studio 2026
1. Создание чистого решения `ELECTROMAGNETIC_TOOLS_3.0.sln` и проекта `ELECTROMAGNETIC_TOOLS_3.0.vcxproj` (C++/CLI x64).
2. Настройка конфигураций `Debug|x64` и `Release|x64` с автоматической сборкой через скрипт `python build.py`.
3. Создание главной формы с карточной компоновкой вкладок (стиль `MAGNETOMETR_CAL`).
4. **Критерий готовности:** чисто компилируемое окно программы в VS 2026 без единого предупреждения.

### Этап 2. Отзывчивые графические окна (Fast Chart Engine)
1. Реализация сетки 2+2 (2 временных окна слева + 2 окна секторов справа).
2. Настройка аппаратной буферизации (`DoubleBuffered`) и скоростного режима серий (`FastLine`).
3. Реализация легковесного вертикального визира времени без перерисовки графика (мгновенный отклик по клику и плавному перетаскиванию).
4. Связывание курсора времени с моментальным обновлением формы 16 секторов справа.
5. **Критерий готовности:** плавная работа графиков со скоростью 60 FPS при 10 000+ точек.

### Этап 3. Сетевой стек и прямая интеграция структур прошивки
1. Подключение заголовков прошивки `CARTOGRAF_FIRMWARE/metro_types.h` и `cyclogram_types.h`.
2. Реализация надежного потокового приемника UDP и последовательного порта COM.
3. Разбор кадров `ALLDATA` и сырых секторов `raw_sector_data_all`.
4. Индикация счетчиков пакетов, потерь и ошибок CRC.
5. **Критерий готовности:** стабильный прием реального или эмулированного потока с прибора.

### Этап 4. Перенос и верификация геофизической математики
1. Перенос проверенных функций из `variable.cpp` (`calk_geo_sph`, `LSM`, расчет гармоник $H_0, H_1, H_2$, мусора $dv$).
2. Расчет геосигналов границы пласта и кривых УЭС ($\rho_{ph}, \rho_{att}$).
3. Вывод параметров шума под графиками секторов ($H_1/H_2$, $dv$, SNR).
4. Сверка расчетов с эталонными данными испытаний № 005.
5. **Критерий готовности:** полное совпадение геосигналов и гармоник со старой программой и скриптом Python.

### Этап 5. Встраивание модуля инклинометрии (`MAGNETOMETR_CAL`)
1. Перенос исходных файлов `ConnectionForm.h`, алгоритмов 2D калибровки и отрисовки годографа из `MAGNETOMETR_CAL`.
2. Интеграция во вкладку «Инклинометрия / Годографы».
3. Проверка калибровки магнитометра MMC5983MA и акселерометра ADXL355 прямо из общего окна.
4. **Критерий готовности:** калибровка инклинометра выполняется внутри единого приложения.

### Этап 6. Оффлайн-модуль и сервис
1. Поддержка Drag-and-Drop для файлов `.bin` и `.las`.
2. Строка состояния с паспортом открытого файла (номер прибора, дата, число кадров, статус).
3. Экспорт данных в CSV («RAW CSV») и запуск внешнего мастера калибровки Python.
4. Интерактивная кнопка быстрой самодиагностики «ТЕСТ».
5. **Критерий готовности:** полноценный рабочий релиз Electromagnetic Tools 3.0.
